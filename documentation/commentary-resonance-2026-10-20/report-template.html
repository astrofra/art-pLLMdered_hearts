Test several passages per interview clip, then let the single closest passage choose its clip. Keep enough context to understand what that passage is actually about.

The installation now uses 132 contextual subtitle-cue passages across 25 clips, aiming for 70 words and retaining the best individual passage per clip. Its commentary prompt stays the same. This study compares 55 recorded comments, eight segmentation strategies, three embedding input formats, and 120 new comments; it does not establish a validated artistic winner.

Embedding task prefixes: a large score increase can be misleading

The original 300M EmbeddingGemma model card specifies different formats for similarity and retrieval. We tested both against bare text. In this corpus, symmetric similarity prefixes raise the mean full-clip cross cosine from approximately 0.126 to 0.409 while leaving known-subject top-1 lookup at 8/8. Interpretive checks




Would cluster-first search be more precise?


We tested 4, 6, 8 and 10 KMeans groups, two seeds each, on all 132 normalised passage vectors in 768 dimensions. The query admits one or two closest normalised centroids, then compares individual passages inside those groups. Overlapping passages are not independent examples.


Groups / seedCosine silhouetteSame winning clip: one group / 55Same winning clip: two groups / 55Coffer retained: one / two groups


A one-group filter loses the concrete coffer association in 6/8 configurations; two groups still lose it in 3/8. Preserving the exhaustive winner is a geometric retrieval diagnostic, not proof of artistic quality. With only 132 candidates, exhaustive matching is inexpensive. These tests support using clusters for exploration rather than as an exclusion filter. Other clustering methods were not tested. scikit-learn’s text-clustering example and limitations




Practical recommendation




Before deploying the passage index, read each unit for a named or recoverable subject: who or what is “it”, “there”, “that” or “the reason”? Join an underspecified passage to its neighbour. Removing hesitations cannot restore a missing antecedent. Preserve the original transcript as evidence.




Integration checks. 29 project tests and four data checks pass. An eight-command Frotz/Ollama run without the renderer or viewer produced two comments and one logged video request. A fresh embedding of the coffer comment selects the expected clip, with only a 0.00267 lead over second place. Saved integration evidence.


Reproducibility. All embeddings use the same local EmbeddingGemma 300M model, 768 dimensions, CPU, explicit 2048 context, truncate=false. Prompt and embedding experiments make no changes to model weights. Some CPU embedding work overlapped GPU generation, so wall times are not a controlled speed benchmark. Raw modern API vectors may differ slightly from the legacy catalogue, enough to swap close rankings.
